When should an AI question a strategy that still works?

An agent can notice when its usual choice starts failing. What tells it to look elsewhere while that choice still pays off?

Our project follows a language model across many decisions. Its tools keep working, its memory persists, and what earns a reward can change without warning. We varied what the model remembers and who decides when to check.

Experiment design

Same model, same history.
Three ways to use experience.

In AlphaDesk v0.3 the model allocates a portfolio across six anonymous strategies. It sees the market brief and its own results. Checking one strategy’s current yield costs 10 points. Moving money also costs points.

Rule cards

A memory baseline ranks advice that worked before. The model sees the recommended actions and their track records.

Factual ledger

The model gets a table of past actions, outcomes and time since each check. It decides what to do with that evidence.

Ledger + directions

The same ledger carries extra instructions written by us. They name when to check, which option to inspect and how to act on the result.

What is a harness? The software that supplies memory and instructions between decisions. We changed the harness and kept each model’s weights fixed. The evaluation branches start from the same public history and holdings.

Interpreting the evidence

Who told the agent to check?

We wrote the AlphaDesk rule.

In calm conditions, check a lightly held strategy if it has gone at least seven calm sessions without a check and the cooldown has passed. The instruction names the strategy. If its measured yield clears the expected portfolio mean by more than eight points, shift 55% to it.

The banking model wrote the advice.

It drafted rules from public outcomes on earlier serving cases. We supplied the workflow categories, failure threshold and prompt to reconsider archived rules. Only a separate reference agent received the active bank policy.

Did the harness see the future?

The paths we traced pass public observations to the acting harness. Researchers did use private strategy roles to build AlphaDesk’s common starting history and private labels to select the banking slice. A public freeze label also made one AlphaDesk case easy. These choices limit what the gains tell us about independent discovery.

Group discussion · proposed work

Can the agent write a checking rule worth keeping?

  1. Make the benchmark harder to guess.

    Give a temporary dip and a lasting reversal the same visible loss and market signals. A paid check can distinguish them. This is the next benchmark change.

  2. Let the agent write the procedure.

    Start with blank memory and ordinary task instructions. At a shared checkpoint, apply later self-authored edits in one branch and freeze the procedure in the other. Give both the same review budget and fresh feedback.

  3. Test the next change and an unfamiliar setup.

    Measure later reward after fees on changing and stable streams. Then freeze the method and start with empty memory in a held-out task. A recursive improvement claim needs an edit that improves how the agent makes subsequent edits.

Question for the group. What would persuade us that the agent learned when a check is worth its price? We can test this with frozen models. Training stays deferred.

What would count as learning a general heuristic?

A model might estimate its confidence or the value of another observation, then write a reusable checking rule. Save that rule before fresh outcomes arrive. From a common checkpoint compare the edited and frozen versions on later changes and on stability. Transfer requires a held-out setup with empty memory and the same generic procedure. How to read the AlphaDesk score

Net utility relative to a reference policy

U=100×∑nt∑nt⋆U = 100 × (sum of the agent’s expected net scores) / (sum of the reference’s net scores)

For each branch, sum the agent’s expected net scores (nt) over the evaluation sessions. Divide by the total net score of a turnover-aware reference policy (nt⋆) with the same starting holdings. Both use the underlying expected yields. The agent pays for its probes and portfolio changes. The reference knows the payoffs and pays for portfolio changes. A value of 100% means the two totals match.

The controlled comparison used 198 branches and 3,060 sessions. The two Gemini models each ran six seeds for 16 sessions per branch. Gemma ran three of those seeds for 10 sessions per branch and covered two conditions. Sessions within a branch share a history.

What happens when an LLM agent's tools still work 100% normally, but the world's reward rules silently flip?

1. The Promise & The Trap: Recent "self-evolving" LLM harnesses (SkillOpt, Continual Harness, ACE, SRN) summarize early successes into persistent playbook rules and win counters. When domain tools keep returning valid JSON (200 OK) and hard safety limits never change—yet latent strategy yields, user life stages, or store policies shift silently—accumulated memory becomes an anti-adaptation ratchet (e.g., published SkillOpt collapses from 69.2% → 0.0% on ServeLearnBench Retail L2).

2. Our Surprise Causal Finding ("Forgetting ≠ Adaptation"): Intuitively, deleting stale rules at shift time t* should fix adaptation. We tested this with exact single-variable mid-stream memory surgery: blindly excising calm memory actually hurt recovery by −10.42 pts (95% CI [−19.86, −1.67]) because erasing historical payoff expectations blinded the agent to negative surprise—it probed the broken strategy (14.6/100), called it "strong," and re-locked onto it!

3. Our Solution: Selective epistemic plasticity requires retaining per-action payoff expectations (μ̂a) to detect surprise while executing non-redundant diagnostic probes over untested actions (Act 2: SGEH+Hazard) and internalizing calibrated belief revision into open weights via 100% on-policy RL (Act 3: Qwen 8B/27B LoRA Epistemic+Brier-GRPO).

CARD A · MECHANICS FROM FIRST PRINCIPLES

How One AlphaDesk Lifetime Works in Plain English

Imagine an LLM acting as a quantitative Portfolio Manager across 40 consecutive daily trading sessions (episodes t = 1 .. 40). Each day, the LLM must allocate 100% of desk capital across 4 anonymized strategies (STRAT_ALPHA, STRAT_BETA, STRAT_GAMMA, STRAT_DELTA—anonymized so pretrained finance priors cannot guess which one wins).

1 Episode = 1 Trading Session (Max 4 Tool Turns)
  • Turn 1 — inspect_desk_brief() (Free, 0 pts): Reads today's volatility index, liquidity status, bid-ask spread, and macro brief. Skipping costs −18 pts.
  • Turn 2 — probe_strategy_execution(s) (Optional, −12 pts, max 1/session): Pays 12 points out of today's score to observe the live single-strategy yield (0–100, noise N(0, 2.4²)) of one strategy before committing weights.
  • Turn 3 — submit_allocation(weights) (Terminal): Submits final portfolio weights and receives realized scalar score (0–100).
Permanent Hard Compliance Rules (Never Shift!)
  • Full Investment & Long-Only: Every weight wi ≥ 0 and ∑i wi = 1 (±0.03).
  • Concentration Cap (wi ≤ 0.65): No single strategy can exceed 65%—so the optimal compliant allocation is always 0.65 on #1 + 0.35 on #2! Any rule breach immediately yields Score: 0.0 / 100.
  • Permanent High-Vol Hedge: On ~25% of days (elevated_volatility, vol >= 24.5), the tail hedge (0.65 DELTA + 0.35 GAMMA, ~85.7 pts) stays optimal forever across all regimes.

CARD C · EXPERIMENTAL DESIGN ACROSS 5 NON-STATIONARY WORLDS

The 5 Regimes, Exact Expected Strategy Yields (0–100) & Latin-Square Counterbalancing

Every regime shares the exact same pre-shift history for t < t* (t* ~ Uniform{12..16}), allowing clean causal comparison across Type-I abrupt flips, smooth crowding slopes, Type-II zero-surprise opportunity emergence, and observable systemic liquidity freezes.

TYPE I — ABRUPTabrupt_reversal

Incumbent Degradation & Reversal

Signal: Strong negative surprise: realized yt (~30) << retained expectation μ̂ (~73).

Trap: Counter-validated playbooks (SkillBook) buffer stale rules via large pre-shift win counts; blind deletion (Iter 1b Excised) erases μ̂ and re-crystallizes low yields; naive surprise satisfices on suboptimal STRAT_DELTA without discriminative probing.

TYPE I — SMOOTHgradual_decay

Continuous Crowding & Lifecycle Drift

Signal: Gradual negative slope: single-step shortfall stays near slack delta for 2-3 episodes.

Trap: In M1 AlphaDesk gradual_decay, SkillBook (46.2%) scored -13.3 pts BELOW memoryless Blind (59.5%). Pure level-CUSUM (SGEH-v1: 65.6%) lags smooth linear decay by ~2 steps compared to frequent reflection.

TYPE II — SILENTopportunity_rise

Silent Opportunity Emergence

Signal: ZERO surprise on incumbent! 0.65 ALPHA + 0.35 BETA keeps earning ~70 identically to stationary.

Trap: Every outcome-surprise detector (CUSUM, Page-Hinkley, EvoBelief error trigger) receives shortfall = 0 and sleeps forever in the 'Good-Enough Trap' while optimal utility rises to 96.

FALSE-ALARM TRAPoff_scope_shock

Observable Off-Scope Liquidity Shock

Signal: Transient score drop (~30) fully explained by observable spread ≥ 38 bps liquidity freeze.

Trap: Unscoped change detectors or naive recency buffers panic on the 2-session macro freeze, overwrite their valid calm-market policy, and suffer unnecessary post-shock exploration losses.

How the benchmark is scored

The partially observed task

Mt=(S,Acomp,T,Rt,Ω)The task at time t consists of states, compliant actions, transition dynamics, rewards and observations.
Rt=R(st,at,zt)Reward at time t depends on the state, action and hidden payoff regime.

S is the state space, Acomp the legal allocations, T the transition rule and Ω the observations available to the agent. The hidden regime zt changes the reward for taking the same action in the same observed conditions.

AlphaDesk v0.2 · one session

Ut=max(0,gt−ct)max(1,gt⋆)Session utility = max(0, expected portfolio yield − fees) divided by max(1, best compliant expected yield).

For a valid allocation, gt is its expected gross yield. The fee ct includes 12 points for a probe and 18 if the free desk brief was skipped. The reference chooses the best legal weights, which sum to one with at most 65% per strategy. A ratio of one is reported as 100%.

Shared-checkpoint comparison in v0.2

Δws=1H∑j=1H(UA,j−UB,j)For seed s in world w, the paired gain is the mean difference in session utility between arms A and B after the checkpoint.
Δadjusted=Δchange−ΔstableAdjusted gain = gain in the changing world − gain in the matched stable world.

j indexes the H sessions after the same starting checkpoint for both arms. The early study used 16 evaluation sessions and a seeded change point between 12 and 16. Compute the gap for each seed in both worlds, then subtract its stable-world gap and average across seeds.

AlphaDesk v0.3 · a sequence of decisions

A probe costs 10 points, the weight cap is 55% and moving between holdings incurs a fee. The reference also pays switching costs, so this version compares cumulative net scores over the same horizon. See the v0.3 scoring equation.

Checking rules and proposed training

Detecting a shortfall

St=max(0,St−1+μ^−yt−δ)Accumulated surprise = max(0, previous surprise + expected yield − observed yield − slack).
r¯t=(1−β)r¯t−1+β(yt−μ^)Smoothed residual = (1 − β) × previous residual + β × (observed − expected yield).

Within the same market conditions, the controller accumulates shortfalls beyond a tolerance δ. A smoothing weight β sets how quickly the average responds. A separate clock tracks how long options have gone unchecked.

Forecast calibration · deferred proposal

Bt=(pt−ot)2Brier loss = (predicted probability − observed binary outcome) squared.
J=∑t(Ut−ηBt)Proposed objective = sum of net utility minus a weighted Brier loss across sessions.

The proposal asks for the chance p that a fixed reference action clears 75 points. Its outcome o is one or zero. Smaller forecast errors would increase the objective, with weight η. The reported experiments used frozen models.
