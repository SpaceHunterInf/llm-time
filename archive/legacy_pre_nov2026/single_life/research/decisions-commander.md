## D001 — Clean subproject, same checkout — 28 September 2026

**Decision:** create `single_life/` with independent dependencies and no runtime imports from the old engine. Do not create nested Git metadata or move/delete historical files. Defer a separate repository until the kernel is accepted or separate publication/collaboration requires it.

**Evidence:** the checkout has many modified/untracked files, competing active-looking plans, and separate pilot/training branches. The earlier audit found runner information-boundary, baseline counting, randomness, and retry-accounting defects. No reusable persistent self-improvement loop was demonstrated.

**Reason:** patching the old runner would preserve inappropriate assumptions and create migration work. A new remote would not resolve scientific ambiguity. An isolated, portable root provides a clean contract while retaining historical evidence.

**Reuse:** port only reviewed units for provider accounting, parsing, or logging when needed. Record origin and tests. Historical reports motivate questions; they are not new-protocol results.
