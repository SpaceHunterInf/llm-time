Group meeting / 29 November 2026

Can an agent rewrite its own learning rule without erasing what works?

Over the past week we moved from hand-written checking controllers to agents that edit their own reviewer rules—and tested an untuned local 8B reviewer before weight training.

Across 95,718 metered calls ($$215.00 of $$70,000 spent), we isolated when factual memory suffices, when paid verification beats rigid alarms, why zero-shot self-editing nets ~0 on average despite +21 to +27 pt wins on individual rules, and what an 8B model must learn.

Foundation · 23 Nov baseline

Same model, same history.
Three ways to use experience.

In AlphaDesk v0.3 the model allocates a portfolio across six anonymous strategies. It sees the market brief and its own results. Checking one strategy’s current yield costs 10 points. Moving money also costs points.

Rule cards

A memory baseline ranks advice that worked before. The model sees the recommended actions and their track records.

Factual ledger

The model gets a table of past actions, outcomes and time since each check. It decides what to do with that evidence.

Ledger + directions

The same ledger carries extra instructions written by us. They name when to check, which option to inspect and how to act on the result.

What is a harness? The software that supplies memory and instructions between decisions. We changed the harness and kept each model’s weights fixed. The evaluation branches start from the same public history and holdings.
