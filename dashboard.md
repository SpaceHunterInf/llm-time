Design a visually stunning, modern project dashboard using a Bento Grid layout, inspired by Apple, Linear, Vercel and contemporary Swiss design.

**Visual language**
- Minimalist, sophisticated and premium.
- Neutral background with a restrained, cohesive colour palette.
- Generous whitespace and consistent spacing.
- Strong typographic hierarchy using Inter or Geist.
- Rounded corners (12–20px), subtle borders and minimal shadows.
- Avoid excessive gradients, unnecessary decoration and generic corporate aesthetics.

**Layout**
- Use an asymmetric Bento Grid composed of modular cards of varying sizes.
- Prioritise important information through card size and placement rather than excessive colour.
- Maintain consistent alignment, padding and visual balance.
- Use a compact sidebar and a minimal navigation header.
- Make the layout responsive across desktop, tablet and mobile.

**Dashboard components**
- Project overview and progress indicators.
- Key performance metrics with miniature trend charts.
- Active projects with status indicators.
- Upcoming milestones and deadlines.
- Recent activity timeline.
- Task completion visualisations.
- Quick actions and contextual information.

**Interactions**
- Subtle hover effects and smooth transitions.
- Expandable cards where appropriate.
- Meaningful loading and empty states.
- Seamless light and dark mode support.
- All interactive elements should be functional, not merely decorative.

**Implementation**
- Use React, Tailwind CSS, shadcn/ui and Lucide icons where compatible with the existing technology stack.
- Build reusable, modular components.
- Preserve existing functionality and backend logic.

The final result should feel like a carefully art-directed, premium software product rather than a conventional admin dashboard. Prioritise clarity, usability and visual harmony. Every card should have a purpose.
